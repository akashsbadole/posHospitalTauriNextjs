# HMS Bugfix Implementation Plan

## Overview
Comprehensive plan to fix 28 bugs across 8 workflow steps in the MediCore Hospital Management System.
**Tech Stack**: Next.js 16 (React 18), TypeScript, Tauri (Rust), SQLite, Zustand, TanStack Query, Zod, date-fns

**Decisions Confirmed** (User responses to clarifying questions):
1. **Patient deletion**: Soft delete with cascading to related records (appointments, prescriptions, lab tests marked is_deleted=1 or status='Cancelled'); invoices preserved for audit.
2. **Prescription inventory validation**: At `issue_prescription` time (when dispensed), not at creation. Check stock availability before decrementing.
3. **Error logging**: Use `eprintln!` with structured format for simplicity; no dedicated DB table needed initially.
4. **Session lock**: Require full re-authentication (username + password) to unlock.
5. **Doctor deletion**: Cancel all future appointments (status='Cancelled', doctor_id=NULL) automatically; past appointments remain.

**Fix** (Soft Delete - Current approach):

2. Add a database trigger OR application logic to also soft-delete or mark related records.

   - Invoices: soft delete or leave as-is (invoices may need retention for billing). **Decision**: Keep invoices intact for audit, but mark patient as deleted.

**Better approach**: Keep patient soft delete, but add cascading updates to related records:
- Update appointments SET is_deleted=1 WHERE patient_id = ?
- Update prescriptions SET is_deleted=1 WHERE patient_id = ?

### Bug 1.10: Fix Age Calculation
**File**: `src/app/patients/page.tsx:136`
**Issue**: Age calculation is `current_year - birth_year`, inaccurate for dates before birthday.
**Fix**:
- Use a proper date-difference utility.
- Create `src/lib/utils/date.ts` with function `calculateAge(dob: string): number`.
- Use `date-fns` `differenceInYears` after adjusting for whether birthday has passed this year.
- Implementation:
```typescript
import { differenceInYears, isAfter, parseISO } from 'date-fns';
export function calculateAge(dob: string): number {
  const birth = parseISO(dob);
  const now = new Date();
  let age = differenceInYears(now, birth);
  // Adjust if birthday hasn't occurred yet this year
  const thisYearsBirthday = new Date(now.getFullYear(), birth.getMonth(), birth.getDate());
  if (isAfter(thisYearsBirthday, now)) age--;
  return age;
}
```
- Replace age calc in `patients/page.tsx` line 136.
